# APSystems ECU-R Control (Modbus TCP)
A free, Python-based Windows application for monitoring and controlling APsystems DS3-L, DS3 and DS3-H microinverters through the ECU-R gateway using Modbus TCP.<br/><br/>
<img src="https://github.com/Strontvlieg/APSystems-ECU-R-Control/blob/main/screenshot.png">
<h4>Features</h4>
<p>
<ul>
  <li>Real-time monitoring of connected microinverters</li>
  <li>Adjustable inverter power limits</li>
  <li>Individual inverter identification through Modbus Unit IDs</li>
  <li>Automatic inverter discovery and continuous monitoring</li>
  <li>Live power measurements and graphical visualization</li>
  <li>Adjustable scanning intervals</li>
  <li>Modbus communication with compatibility fallback</li>
  <li>Dark-themed graphical interface</li>
  <li>No additional Python packages required</li>
</ul>
</p>
<h4>Requirements</h4>
<p>
  <ul>
    <li>Windows PC with Python 3.10 or newer</li>
    <li>APsystems ECU-R gateway with Modbus TCP access</li>
    <li>Compatible APsystems DS3-series microinverters</li>
  </ul>
</p>
