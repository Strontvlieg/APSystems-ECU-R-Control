# APSystems ECU-R Control (Modbus TCP)

A free, Python-based Windows application for monitoring and controlling APsystems DS3-L, DS3 and DS3-H microinverters through the ECU-R gateway using Modbus TCP.

Features
- Real-time monitoring of connected microinverters
- Adjustable inverter power limits
- Individual inverter identification through Modbus Unit IDs
- Automatic inverter discovery and continuous monitoring
- Live power measurements and graphical visualization
- Adjustable scanning intervals
- Modbus communication with compatibility fallback
- Dark-themed graphical interface
- No additional Python packages required

Requirements
- Windows PC with Python 3.10 or newer
- APsystems ECU-R gateway with Modbus TCP access
- Compatible APsystems DS3-series microinverters
